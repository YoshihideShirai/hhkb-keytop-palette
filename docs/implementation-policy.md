# 実装ポリシー

## 見た目の参考ルール

キーボード本体、キートップ、刻印、色味、質感、形状の見た目を調整するときは、PFU DirectのHHKBページに掲載されている商品画像を主な参考情報とします。

https://www.pfudirect.jp/hhkb/

- 本体色、キー色、刻印位置、刻印コントラスト、筐体の印象は、PFU Direct上のHHKB本体およびキートップセットの商品画像を優先して合わせる
- 複数の参考情報で見た目が食い違う場合は、PFU Directの商品画像を第一候補として判断する
- このアプリは非公式シミュレーターのため、完全な再現ではなく、購入前に配色の雰囲気を掴める実機寄りの表現を目指す
